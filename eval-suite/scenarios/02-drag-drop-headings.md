# Drag & Drop: Heading Sections

## Setup
Navigate to the outline editor. Note the order of section headings.

## Actions

### 2.1 Hover reveals drag handle
- Move the mouse cursor to the left edge of any section heading (e.g., "Conclusion").
- A drag handle icon (dots or grip icon) should appear to the left of the heading.

### 2.2 Hover highlights section
- While hovering near a heading, the heading AND all content below it (bullets, citations) up to the next heading should be visually highlighted with a background color or border.

### 2.3 Drag heading reorders sections
- Note the current order of headings.
- Click and drag the last section heading upward, past at least one other heading.
- Release the mouse.
- The headings should now appear in a different order than before the drag.

### 2.4 Section content moves with heading
- After the drag in 2.3, the bullet points and any other content that was under the moved heading should still be under it in the new position.
- Content from other sections should NOT have moved or become orphaned.

### 2.5 No spacing artifacts after drag
- After the drag, there should be no extra blank lines or unusual gaps between sections.
- All headings should have consistent vertical spacing between them.

### 2.6 Escape cancels drag
- Start dragging a heading (click and begin moving).
- Press the Escape key.
- The heading should return to its original position.
- No visual artifacts (dimmed elements, floating previews) should remain.
