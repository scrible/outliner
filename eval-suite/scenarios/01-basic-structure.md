# Basic Document Structure

## Setup
Navigate to the outline editor. Wait for content to load.

## Checks

### 1.1 Title heading exists
- There should be a large, bold heading at the top of the editor (H1).
- It should contain the text "Mars Colonization" or similar title text.

### 1.2 Section headings exist
- Below the title, there should be multiple section headings in a smaller size and teal/blue-green color.
- Expected headings include: "Thesis", "Background", "Economic Feasibility", "Conclusion" (or similar).

### 1.3 Bullet lists under headings
- Under at least one heading, there should be bulleted list items (• or similar markers).
- The bullets should be indented relative to the heading.

### 1.4 Ordered lists exist
- There should be at least one numbered list (1. 2. etc.) visible in the editor.

### 1.5 Nested lists
- Under at least one numbered list item, there should be indented bullet items (sub-items).
- The sub-items should be visually indented further than their parent numbered item.

### 1.6 Citation exists
- There should be at least one citation-styled element: italic text with a gold/amber left border and light gold background.
- The citation should contain author and title information in an academic format.

### 1.7 No empty gaps
- There should be no large unexplained vertical gaps between elements.
- Spacing between sections should be consistent.
