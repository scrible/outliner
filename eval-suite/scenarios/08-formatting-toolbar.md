# Formatting Toolbar

## Setup
Navigate to the outline editor. Select some text in a list item by clicking and dragging across it.

## Actions

### 8.1 Bubble toolbar appears on selection
- After selecting text, a floating toolbar should appear near the selected text.
- The toolbar should have a dark background with light-colored buttons/icons.

### 8.2 H1/H2/H3 toggle buttons
- The toolbar should show H1, H2, H3 as individual buttons (NOT a dropdown).
- When the cursor is in a heading, the corresponding button should appear highlighted/active.

### 8.3 Bold/Italic/Underline work
- Select some text and click the Bold button in the toolbar.
- The selected text should become bold.
- Repeat for Italic and Underline.

### 8.4 List buttons don't remove list
- Place cursor in a bulleted list item.
- Select some text to show the toolbar.
- Click the bullet list button.
- The text should remain in a bullet list (NOT be converted to plain text).

### 8.5 Toolbar above other UI elements
- When the toolbar appears, it should render above (on top of) any drag handles, hover overlays, or other UI elements.
- The toolbar should not be clipped or hidden behind other elements.

### 8.6 No clean/remove-formatting button
- The toolbar should NOT have a "remove formatting" or eraser/clean button.
