# Source Panel

## Setup
Navigate to the outline editor.

## Actions

### 6.1 Sources button opens panel
- Click the "Sources" button in the top-right toolbar area.
- A panel should appear on the right side showing a list of sources.

### 6.2 Source cards show metadata
- Each source card in the panel should display: a favicon/icon, a title, author name, and year.

### 6.3 Click source opens detail
- Click on a source card (short click, not a drag).
- A detail view should appear showing: a larger preview image or thumbnail, the source title as a link, author and date, a summary description in italics, and an "Insert Citation" button.

### 6.4 Detail close returns to list
- In the detail view, click the back arrow or X button.
- The detail view should close and the source list should reappear.
- The panel itself should NOT close.

### 6.5 Drag source inserts citation
- From the source list, click and drag a source card toward the editor area.
- Drop it somewhere in the editor.
- A citation should be inserted at or near the drop position with gold/amber styling.

### 6.6 Panel doesn't shift editor
- Note the horizontal position of the outline content.
- Open and close the source panel.
- The outline content should NOT shift horizontally when the panel opens or closes.
